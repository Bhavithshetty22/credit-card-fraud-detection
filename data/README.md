# Data Directory

This directory is designated for storing dataset files used in the Credit Card Fraud Detection project.

## Expected Dataset
- **European Credit Card Fraud Detection Dataset** (`creditcard.csv`)
- **Features**: `Time`, `V1` through `V28`, `Amount`, `Class`
- **Total Records**: ~284,807 transactions
- **Target Variable**: `Class` (0 = Legitimate, 1 = Fraudulent)
